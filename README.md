# Pawan Kalyan — Final Portfolio

Premium light editorial portfolio with glassmorphism, champagne-gold + deep-navy palette, animated hero portrait, floating role cards, responsive navigation, animated `code | intelligence` typewriter, skills, projects, journey and contact sections.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The build command intentionally invokes Vite through Node (`node node_modules/vite/bin/vite.js build`) to avoid Vercel/Linux executable-permission issues with `node_modules/.bin/vite`.

## Deploy to Vercel

- Framework: Vite
- Root directory: `./`
- Build command: `npm run build`
- Output directory: `dist`
